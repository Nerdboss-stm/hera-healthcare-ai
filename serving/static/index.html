Multi-Agent Clinical Reasoning Pipeline
💡

What's happening here?

When you hit "Run Pipeline", three AI agents analyze the patient in sequence — just like a real ER team. The Triage Agent decides how urgent the patient is (ESI level 1-5). The Diagnostic Agent then generates ranked diagnoses with ICD-10 codes based on symptoms. Finally, the Treatment Agent creates a medication plan, automatically checking for drug interactions and allergies. All three results combine into a consensus score with a full audit trail showing exactly how each agent reasoned.

RAG Medical Knowledge Base
💡

What's happening here?

This is Retrieval-Augmented Generation (RAG) — a key technique in modern AI. Instead of hallucinating answers, the system searches a vector database of 16 real medical guidelines (AHA, IDSA, ESC, GOLD, WHO) using semantic similarity, then returns the most relevant passages with source citations. The search uses FAISS (Facebook's vector similarity library) and sentence-transformers for encoding text into 384-dimensional embeddings.

Clinical Entity Extraction + Knowledge Graph
💡

What's happening here?

This runs Named Entity Recognition (NER) on clinical text to automatically find medications, conditions, procedures, and lab values. Each entity is linked to UMLS medical codes (the universal medical vocabulary). Then it builds a patient knowledge graph showing how everything connects — which drugs treat which conditions, what tests diagnose what, and potential interactions. The graph is visualized in real-time.

FHIR R4 Interoperability
💡

What's happening here?

FHIR (Fast Healthcare Interoperability Resources) is the US government-mandated standard for exchanging healthcare data between systems. This demo accepts a real FHIR R4 Bundle containing patient demographics and vital signs, runs it through the risk prediction model, and returns a FHIR-compliant RiskAssessment resource that any hospital EHR system could consume. Bidirectional conversion means this system can both read from and write to any FHIR-compatible system (Epic, Cerner, etc.).

LLM-as-Judge — AI Safety Evaluation
💡

What's happening here?

This is an AI safety framework that evaluates whether an AI-generated medical summary is safe and accurate. It scores on 4 axes: Factual Consistency (are the claims supported by the source?), Hallucination Detection (did the AI invent information?), Medical Accuracy (are drug names/dosages valid?), and Clinical Safety (could this output harm a patient?). Unlike simple ROUGE metrics, this catches genuinely dangerous errors like incorrect dosages or contradictions.

Patient Risk Prediction
💡

What's happening here?

A Random Forest classifier analyzes 7 vital signs and automatically computes derived features (BMI, MAP — Mean Arterial Pressure). It outputs a risk classification with confidence score. In production, this would use SHAP values for model explainability so clinicians understand why the model flagged a patient.
